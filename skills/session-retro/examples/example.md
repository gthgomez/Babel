# Example

User task:

```text
The deploy check said the feature was missing. Investigate yourself.
```

Expected behavior:

- Mode is on-error, scoped to that single false report.
- Evidence quotes the command and output, labeled `[PROVEN]` or `[UNKNOWN]`.
- The why-trace ends in exactly one taxonomy category.
- The lesson is an imperative directive, written to memory or the instructions file, and the full record is appended to the retro log.
- A second occurrence of the same cause becomes a mechanical guard in this session, not another prose note.
- The full worked record is `references/example-retro.md`.
