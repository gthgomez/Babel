# Visual Variant Matrix Protocol for Asset Work

Read this rule when performing visual design, UI mockup creation, icon drafting, or asset generation.

---

## 1. Upfront Variant Generation Rule

- **No Single-Variant Micro-Steering:** When requested to design, audit, or iterate on visual assets (e.g. app icons, UI screens, promotional graphics), generate **3 to 4 distinct, named variants upfront in Turn 1**.
- **Naming Convention:** Save variants with explicit, descriptive filenames (e.g., `variant_1_minimal_white.png`, `variant_2_neon_glow.png`, `variant_3_blueprint_flat.png`).

---

## 2. Visual Comparison Handoff Format

Present image generation results using markdown carousels or structured image grids.

---

## 3. Decision Gate

- Prompt the user to select their preferred variant by number/name before performing code integration or file copying.
- Eliminates multi-turn trial-and-error loops.
