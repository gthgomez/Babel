# Babel contributor instructions

AGENTS.md alone owns contributor policy for `gthgomez/Babel`: the sole repository instruction authority; model/vendor instruction files are prohibited. Read AGENTS.md in full once before repository work; a prompt excerpt is incomplete. Babel packages use this root file; workspace-template offers to save nested instructions do not apply. ## Independent review and merge

- Readiness: `scripts/agent-pr-gate.ps1 -PR <n> -ReviewedHeadSha <sha>`; draft `-AuditOnly` reports BLOCKED without CI polling, never acceptance. Merge requires permission/authorization, independent exact-head review, resolved reviews/threads, current base, green exact-head checks: `scripts/agent-pr-merge.ps1 -PR <n> -ReviewedHeadSha <sha> -RepoRoot <clone>`; trusted immutable-base gate binds reviewed/remote/PR/CI heads before expected-head merge; no admin bypass/candidate self-certification. Merges changing any path matched by `hostProtectedPrefixes` (`config/review-risk-policy.json`) need explicit owner authorization, as do organization-required human approvals. Otherwise, authorized gate-green tasks need no repeated approval.
- Handoffs carry approval scope, superseded restrictions and user-message provenance; they record authority, grant none. Check history before asking again; elapsed time never grants approval.
- Ordinary push: `pwsh tools/check-public-content-policy.ps1 -RepoRoot .` and `pwsh tools/run-public-secret-scan.ps1 -RepoRoot . -Strict -RequireExternalScanner`. Maintainer pre-merge: clean `pwsh tools/validate-public-release.ps1 -Strict -RequireSupplementalPolicy`, using the real `BABEL_PRIVATE_SCRUB_POLICY_PATH` or approved `-SupplementalPolicyPath`; configured policy applies to ordinary scans. Absence blocks maintainer pre-merge, not ordinary push. Never empty/unset/fabricate/ weaken it. Hooks/helpers cannot waive guards.
- Never read credential files or dump them via shell: `.env` variants, private keys/stores, `secrets/`, SSH/cloud credentials. Inspect names/presence only. Approved review resolvers may call credential helpers in memory; never print outputs. Operators configure missing secrets. No tokens in args, logs, remotes, config, commits or handoffs.
- No public secrets/private identifiers/home-machine paths/task ledgers/prompt exports/datasets/scratch/evidence dumps; supplemental policy stays outside Git. On exposure, don't repeat values; request rotation/revocation. Committed/pushed secrets are compromised; Git cleanup cannot restore trust.
- Proceed within authorized scope; no repeated approval. Record acceptance/ invariants/proof/recovery. Try reversible experiments; ask for unclear intent/ new authority/credentials/unbudgeted spend/irreversible effects. Force-push, shared/unknown history rewrite, branch deletion, destructive cleanup, open-PR hard reset, direct main/master push, deployment, migrations or security/ infrastructure changes need exact owner scope and recorded reason. Checks/repo evidence never authorize bypass. Authorized history repair: impact/remote-owner checks, frozen expected head, bounded `--force-with-lease=<ref>:<expected-sha>`, resulting-ref verification; non-lease force prohibited.
- No global Git/SSH/credential config/remotes changes to bypass auth. Repo-local credential-helper edits need explicit scope; in-scope work may seek per-action host approval. Respect reviewer/policy denials; no blanket escalation or host admin/security changes.
- Review in a separate execution when available: exact base/head, full diff/ source, intent/proof. Any harness/model may review, including the same model in a separate run. PR records SHA/findings/issues/limits; keep rejection/repair/ re-review. No invented isolation/attribution/evidence. Babel certification is optional; V3 evidence requirements remain.
- Required checks: live `protect-main`; expected: current workflows. Preserve `security`, `public-content-policy`, `linux-validation`, `public-pr-metadata`, `windows-portability` and all live checks. `scripts/agent-pr-gate-common.psm1` resolves exact-head producer event/workflow/app and latest authoritative result. Old success cannot override newer failure/pending; non-authoritative twins certify nothing. Privileged `pull_request_target` jobs execute trusted-base content only.

## Delivery and verification

Managing agent owns Git mutations. Delegates get task/revision/checks/paths/patch permission. Reviewers never stage/commit/push/merge/deploy. Resolve safety/scope/verification disagreements first.

1. Before delivery: `pwsh scripts/agent-preflight.ps1` verifies repo/branch/remote/worktree. Noninteractive Git/gh; needed `-GitPath`/`-GhPath`. Read/auth failures stop dependent work only. Refresh changed context/remote evidence, not wrappers/staging. Substantial work: `scripts/agent-worktree.ps1 -Action create -Name <task>`; `codex/` branch from current main or exact authorized PR head. Check main/open PRs. Rejected push: fetch/freeze, classify ownership, sync safely; no automatic rebase/force.
2. `git status --porcelain=v2 -z --untracked-files=all`: assign ship/split/vault/exclude/investigate/local-helper to every path. Ship coherently; assess risk early; keep release map and unrelated work/evidence/snapshots. CLI edits use `src/`, not `dist/`. Exclusion destroys nothing. No unexpected artifacts/lockfiles without dependency intent.
3. Focused checks, small conventional commits, staged diff/path review. Stage explicit ship paths; no blind `git add -A`/`git add .` on mixed work, unexplained dirs or staged-and-unstaged paths. Scan private doc paths; batch repairs/pushes. Check scan policy/config, review scope, supported private transfer and installer/runtime dependencies early. Report failed stage before dependent delivery.
4. Focused proof; expand for shared contracts. Product: `npm --prefix babel-cli run typecheck`. CLI code: build/relevant tests. Catalog/routing: `pwsh tools/validate-all.ps1` trio. Large files: `pwsh tools/check-architectural-budget.ps1`. Scripts/workflows own commands; raw `npx tsc` is not canonical. Docker/release checks != hosted CI; helpers cannot mandate quick/full/Docker cycles.
5. Reuse proof only for unchanged inputs/lock/command/tool/policy/runtime/platform/environment; record basis. Repairs invalidate affected proof. Batch fixes; diagnose before reruns. Required hosted checks finish; review exact head. No old-head proof, skip-CI, hidden omissions or wrapper repeats. Before final CI, inspect live draft/readiness, review blockers and dependencies/base. Repair dependencies before bundle qualification. After waits, refresh head/base/readiness/reviews/checks; old metadata cannot accept current work. Identical-source readiness changes refresh trusted audit, not product CI. Keep exact-head/base binding and all security/integration gates.
6. Direct-base size: `git diff --numstat <base>...HEAD` and `git diff --name-only <base>...HEAD`. 1,500 additions+deletions / 30-file limits are advisory, not automatic blockers/repeated approvals. Above either, record counts/ownership/coherence/reviewability; split at useful semantic boundaries. Keep review depth, architecture budgets, executable safety and resource/spending limits. Stacks aid review; readiness uses current main.
7. Draft PR: problem/behavior, included/excluded/deferred scope, dependencies/size, checks/skipped/failed proof/risks/follow-ups. No CI bypass. Verify merge commit/post-merge CI. Handoff: branch/SHA, PR/merge links, changed/excluded paths, proof/reuse basis/receipts/blockers/risks. Separate merge outcome from temp-file cleanup. After MERGED plus cleanup failure, verify live PR/merge SHA and report cleanup; never retry a confirmed merge. Diagnose genuine merge failure; it remains failed.

Report blocker command, exit/result and stage: local/push/maintainer pre-merge/merge. Try permitted harmless connector reads before universal-outage claims. Respect denied network; connectors cannot replace required trusted wrappers.

Authorized local-main sync: fetch/freeze SHA; clean tracked tree/index; no untracked **or ignored** collisions, including file/directory prefixes. Preserve dirty/colliding bytes: path `git hash-object` == recorded commit/stash blob; refs save committed bytes only. Back up divergence; switch without force; recheck before reset; retain backups until separately cleared. No open-PR reset/remote-main rewrite.
