# Babel Run Intelligence source map

Status labels are deliberately narrow: **VERIFIED_CURRENT_SOURCE** means directly inspected in the current checkout; **HISTORICAL_UNKNOWN** means a present-day parser must not assume older evidence has that form.

| Evidence family                        | Producer / consumer                                                                                                        | Identity & mutability                                                                             | BRI adapter status                                                                                                                                             |
| -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Timestamped evidence bundle            | `babel-cli/src/evidence.ts` writes `runs/<timestamp>_<nonce>_<slug>`; pipeline and evidence commands consume it            | Directory name is a legacy locator, not semantic identity. Historical stores are read-only.       | **VERIFIED_CURRENT_SOURCE**: `evidence-bundle-read-only` records a source digest, artifact occurrence, and receipt.                                            |
| Session events                         | `agent/sessionEvents.ts` appends `session-events.jsonl`; resume/diagnostics consume it                                     | `session_id`, `event_id`, `seq`; append-only JSONL.                                               | **VERIFIED_CURRENT_SOURCE**: bounded JSONL parser extracts session locator, model identity when present, and deterministic tool/provider failure observations. |
| Revision-bound Chat verifier receipt   | `evidence/chatRevisionBinding.ts` attaches `boundRevision`, explicit authority, scope, and stale state to `verifier_attempt` | A full-suite authoritative receipt can establish a test result for its composite-tree hash; it does **not** establish general task correctness without a task-specific authority contract. | **VERIFIED_CURRENT_SOURCE**: BRI records `TEST_CORRECTNESS` only for an authoritative, full-suite, revision-bound receipt; stale and malformed bindings remain non-valid evidence. |
| QA verdict artifact                    | `03_qa_verdict_v*.json` is consumed by finalization/proof paths                                                         | Pipeline QA control decision; historical artifacts do not carry independent reviewer provenance or revision binding. | **CONTROL_ONLY**: not normalized as task correctness. |
| Terminal status summary                | Pipeline finalization writes `terminal_status_summary.json`                                                               | Execution/control lifecycle state, not software correctness. | **VERIFIED_CURRENT_SOURCE**: normalized as `TERMINAL_EXECUTION_STATUS` only. |
| Execution report / terminal summary    | pipeline finalization and structured-output paths write/read `04_execution_report.json` and `terminal_status_summary.json` | Run-local derived report; fields vary across historical eras.                                     | **HISTORICAL_UNKNOWN**: recorded as artifact only. A report status or agent text is not promoted to an `OutcomeObservation`.                                   |
| Checkpoints                            | `services/checkpoints.ts` and session checkpoint surfaces                                                                  | Recovery evidence is run-local; `available` does not prove a complete workspace recovery profile. | **PARTIAL**: checkpoint artifacts are inventoried only; no restore claim is inferred.                                                                          |
| FTS                                    | `services/ftsIndex.ts` / `services/indexer.ts`                                                                             | Separate local index, not a run corpus.                                                           | **VERIFIED_CURRENT_SOURCE**: untouched. BRI does not read, write, vacuum, or certify it.                                                                       |
| OpenTelemetry                          | `telemetry/tracing.ts`                                                                                                     | Trace context is evidence, not a competing telemetry backend.                                     | **PARTIAL**: trace-context artifacts are inventoried only; no exporter is introduced.                                                                          |
| Cost / usage                           | evidence bundle `cost_ledger.json` and cost services                                                                       | Availability depends on writer/schema.                                                            | **PARTIAL**: artifact occurrence only until a versioned ledger adapter is added.                                                                               |
| Benchmark / review / regression ledger | benchmark modules, review surfaces, `REGRESSION_LEDGER.md`                                                                 | Human-led, version-specific evidence.                                                             | **NOT_ESTABLISHED** for automatic normalization; no prose relationships are inferred.                                                                          |

The adapter never copies, rewrites, or opens a historical SQLite/FTS database. It uses bounded reads of immediate files and persists derived facts only in the selected local BRI catalog.
