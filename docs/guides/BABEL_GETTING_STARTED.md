# Getting started

This page used to tell you to clone the repo and build inside `babel-cli`. That is the contributor build, not the first path.

Start with the [README](../../README.md) or [START_HERE.md](../../START_HERE.md):

```sh
node --version
npm install --global babel-harness@0.2.0
babel-harness --version
babel-harness doctor
```

Node.js 22.19.0+ on the 22 line, or 24.13.1+ on the 24 line, is required. If a command fails, see [Troubleshooting](../TROUBLESHOOTING.md).
